# Känner du boten?

Ett chattspel där 2–5 spelare och en hemlig AI chattar, och röstar om vem som är boten.

**Spela här:** https://whoisthebot-frontend.onrender.com

> Spelet körs på Renders gratisnivå. Backenden somnar efter 15 minuter utan trafik,
> så det första anropet som görs kan ta upp till en minut innan något händer.
